# Novi 产品需求文档（PRD）

## 1. 产品定义

Novi 是 AI Knowledge Scientist：将主题、问题或研究想法转化为可持续积累的知识资产。产品聚焦三个场景，不定位为通用聊天助手。

1. Knowledge Builder：生成结构化 Wiki、学习路线、知识图谱、案例与可验收 Practice Lab。
2. Deep Research：同时生成研究报告、LLM Wiki、知识图谱、SOTA 分析、证据地图和研究机会。
3. Paper Author：从想法依次形成 research gap、novelty matrix、完整论文结构、方法、实验计划和模拟审稿意见，并导出 IEEE/ACM LaTeX。

## 2. 用户与价值

| 用户 | 核心任务 | 可验证价值 |
| --- | --- | --- |
| 工程师、学生 | 快速进入新领域 | 获得分阶段学习路径和可复用知识库 |
| 科研人员、架构师 | 调研技术与前沿 | 获得证据结构、SOTA 与明确研究缺口 |
| 论文作者 | 把研究想法变为计划 | 获得可审查的方法、实验和 LaTeX 草稿 |
| 企业研发团队 | 沉淀团队知识资产 | 后续版本提供团队权限、私有数据源和持续更新 |

## 3. 核心旅程

用户进入工作台，选择场景，输入工作空间名称和主题，创建工作空间并生成成果。用户可以导入笔记、网页、PDF 或代码库，在 Workspace knowledge 中浏览、语义检索或删除错误、过期和敏感文档；重新生成时，Novi 检索与主题相关的工作区知识并把实际使用片段固化到成果版本，供用户核查。删除文档会清除活跃语义记忆和外部投影，但已经生成的不可变成果仍保留当时使用的 excerpt；完整清除需删除工作空间或账户。用户还可以在不同成果视图间切换、置顶项目、复制摘要、导出 Markdown；论文成果支持导出 LaTeX。每次重新生成都会保留不可变版本，用户可选择历史版本、与上一版逐节比较并导出指定版本。手动刷新或每日/每周关注任务会比较已应用来源基线；发现论文、技术资料或 GitHub 等来源新增、更新或移除时，在额度和权限允许的情况下自动检索工作区知识并生成新的不可变成果版本，失败、忙碌或额度不足的变化会在后续周期重试。历史项目持久保存，下次打开继续使用。

## 4. 范围与优先级

### P0（当前版本）

- 三种工作空间的创建、浏览、生成与重新生成。
- Wiki、学习路线、Practice Lab、知识图谱、报告、SOTA、机会、research gap/novelty、完整论文、方法、实验、可渲染矢量图表和审稿视图。
- 每个成果固化 Research、Knowledge、Writing、Review 四阶段 provenance，不运行无边界 Agent 对话。
- 本地持久化、健康检查、参数校验、Markdown/LaTeX 导出。
- 不可变成果历史、历史版本选择、逐节比较和指定版本导出。
- 来源变化检测、手动/每日/每周持续刷新，以及变化驱动的自动不可变成果版本。
- 个人知识文档导入、浏览、语义检索、单文档删除，以及检索片段驱动的生成上下文闭环。
- 可选隔离 Browser Agent 导入 JavaScript 渲染页面；可选 MCP Streamable HTTP 工具补充结构化来源。
- 响应式 Web UI 与 Electron Desktop UI。
- 无外部服务时可演示和完成完整流程。

### P1（商用上线前）

- 接入真实检索供应商、LLM 与向量/图存储。
- 账号、组织、RBAC、用量计费、支付订阅、审计日志与数据删除。
- 引用级证据溯源、事实核验、异步任务和失败恢复。
- PDF/网页/代码库导入的目标供应商和大规模语料生产验收。

### P2

- 团队协作、评论、企业 SSO、私有化部署。
- 多语言、模板市场、领域评测集和管理后台。

## 5. 成功指标

- 新用户在 3 分钟内生成首个完整知识资产。
- P0 核心旅程成功率不低于 99%。
- 生成成果每个事实性结论具备可点击来源（P1 上线门槛）。
- 30 日内重复打开或更新知识资产的用户比例不低于 35%。

## 6. 商业边界

商业目录为 Personal Knowledge $29/月、Pro Research $99/月、Enterprise $1000+/月；Web 公开比较额度，但 checkout 只调用已配置的真实支付 provider。当前 `0.1.0` 已包含账户/租户隔离、组织成员/RBAC、异步 Job、审计、数据导出/删除、实时来源连接器、隔离 Browser Agent 和通用 MCP source adapter、OpenAI-compatible 模型网关、配额和支付 provider 边界；live/MCP source URL 已有可访问性、内容哈希和 claim 映射验证，但仍不宣称事实已经由人工或领域专家核验。生产基线已提供 PostgreSQL + pgvector/HNSW、对象存储（本地/Bearer gateway/SigV4 S3-compatible）和 Neo4j 适配器，以及持久外部投影 outbox；工作区语义检索结果进入生成并随不可变成果保存，模型被明确告知检索文本是不可信数据。无 pgvector 时只允许开发/迁移回退，生产门禁要求原生向量存储。本地已完成依赖审计、SBOM/许可证元数据检查、生产镜像扫描和 Linux AppImage 窗口验证，并提供固定 action SHA 的三平台发布流水线。正式收费和生产开放仍必须完成真实支付/OIDC/LLM/S3/Neo4j/Browser Agent/MCP 目标服务验收、备份恢复演练、正式公网压力测试、托管 CI/签名/公证与外部渗透测试、Windows/macOS 安装升级 E2E，以及目标规模向量/图检索容量演练。
